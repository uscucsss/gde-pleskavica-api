# GdePleskavica — каталога кафан Белграда

Веб-приложение со встроенной защищенной панелью администратора для динамического управления каталогом заведений и меню.

## Архитектура и технический стек
- **Серверная часть:** Фреймворк FastAPI на Python 3.14+ под управлением сервера Uvicorn.
- **База данных:** СУБД SQLite3. Логика инициализации таблиц защищена от перезатирания существующих коммерческих данных при перезапусках сервера. Связи между таблицами кафан и блюд реализованы через внешние ключи (Foreign Keys).
- **Безопасность:** Изолированное хранение секретов в конфигурационных файлах окружения. Реализовано хэширование паролей по алгоритму SHA-256. Защита сессий и CRUD-операций админа построена на механизме авторизационных кук с флагами безопасности HttpOnly и SameSite. Настроен сквозной CORS-фильтр для безопасных локальных сетевых запросов.
- **Клиентская часть:** Легкий интерфейс на чистом стеке Vanilla HTML5, адаптивных сетках CSS Grid / Flexbox и асинхронном JavaScript (Fetch API).

## Реализованный функционал
- Публичный эндпоинт генерации структурированного JSON-пакета данных с автоматической вложенностью актуального меню в карточки заведений.
- Изолированная панель управления с жестким ограничением прав доступа (401 Unauthorized для неавторизованных запросов).
- Полноценный административный CRUD: создание новых точек на карте, динамическое добавление позиций меню, изменение цен в национальной валюте (RSD) и удаление блюд.
- Асинхронный рендеринг интерфейса и микро-анимации карточек на фронтенде без принудительной перезагрузки страницы браузера.
